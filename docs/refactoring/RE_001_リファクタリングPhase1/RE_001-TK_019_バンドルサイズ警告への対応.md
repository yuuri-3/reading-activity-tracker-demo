# P2-RE_001-TK_019 バンドルサイズ警告への対応（分割/分析）

このチケットは、`npm run build` 時に出ている bundle サイズ警告（約 1MB など）を受け、将来のパフォーマンス悪化に備えて対処方針を決めます。

## ゴール

- 何が大きいか（原因）が把握できている
- 必要ならコード分割/遅延読み込み等で改善できる

## 対象

- `vite.config.ts`
- ビルド出力（dist）
- 依存の重い UI/チャート等（調査で判明する範囲）

## 実装状況

Status: ⬜ 未着手

## 受け入れ条件

- [ ] バンドル肥大の主要因が特定されている（依存/ページ/機能）
- [ ] 改善案が決まり、必要なら実装されている（最小差分で OK）
- [ ] `npm run build` が通る

## 作業内容

- まずは分析（どのチャンクが大きいか）
- 対策（例）
  - 画面単位の lazy load
  - heavy dependency の読み込み箇所の見直し
  - Vite/Rollup の chunk 分割設定

## 非ゴール

- すべての画面を一気に最適化
