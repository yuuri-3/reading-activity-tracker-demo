# TK-031 書籍選択プルダウンから新規書籍を登録

このチケットは、書籍選択のプルダウンで新規書籍をそのまま追加できるようにする。挙動は「タグ選択 UI と同じ」だが、書籍は **単一選択のみ** とする。

## ゴール

- 書籍選択プルダウンから新規書籍を登録できる
- 既存の書籍選択フローを壊さず、単一選択を維持する
- UI/UX はタグ選択 UI に揃える（複数選択のみ不可）

- [src/app/pages/TimerPage.tsx](../../src/app/pages/TimerPage.tsx)
- 書籍選択コンポーネント（該当箇所）

## 受け入れ条件

達成チェック:

- [ ] 書籍選択プルダウンで新規書籍名を入力して追加できる
- [ ] 追加後、その書籍が即座に選択状態になる
- [ ] 既存の書籍選択（一覧からの選択）は従来通り動作する
- [ ] 書籍は単一選択のみ（既存の書籍が選択されている場合は置き換え）
- [ ] 同名書籍の重複追加を防止できる（既存書籍がある場合はそれを選択）
- [ ] 空文字や空白のみの入力は登録できない

## 作業内容

### 1) UI/UX の方針確定

- タグ選択 UI の挙動に合わせる（入力 → 候補フィルタ → 追加）
- 書籍は単一選択のため、選択済み状態では「置き換え」動作にする

### 2) 書籍追加フローの実装

- 既存の書籍追加 API を再利用して新規書籍を作成
- 作成完了後、作成した書籍 ID を選択状態に反映

### 3) バリデーションと重複防止

- 既存タイトルと一致する場合は新規作成せず、既存書籍を選択する
- 空文字/空白のみは追加不可

### 4) デザイン依頼（必要な場合）

- タグ選択 UI と同様の「新規追加」導線の見た目を整える
- 画面のどこで入力・追加を行うか（候補リスト内 or フッター）をデザインで確定

## 非ゴール

- 書籍の詳細編集（著者・メモ・表紙など）
- 複数書籍の同時選択
- 既存の書籍一覧画面の UX 改修

## 注意

- 書籍追加はタグ追加と違い **単一選択** である点を UI 上で誤解させない
- 既存の検索・フィルタ挙動を壊さない
