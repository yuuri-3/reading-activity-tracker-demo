# TK-032 書籍詳細の記録メモ編集 UI 統一

このチケットは、書籍詳細画面から記録メモを編集する際の仕様・UI を、記録画面（RecordSingleView）での編集仕様に揃える。編集項目・バリデーション・保存フローを統一し、利用者が迷わないようにする。

## ゴール

- 書籍詳細画面の記録メモ編集 UI/仕様を記録画面と統一する
- 同じ入力項目/挙動/バリデーションで編集できる
- 編集後の表示更新が一貫して行われる

## 対象

- [src/app/pages/BookSingleView.tsx](../../src/app/pages/BookSingleView.tsx)
- [src/app/pages/RecordSingleView.tsx](../../src/app/pages/RecordSingleView.tsx)
- 記録編集フォーム（共有化する場合のコンポーネント）

## 実装状況

Status: ⬜ 未着手

## 受け入れ条件

達成チェック:

- [ ] 書籍詳細画面の記録編集 UI が記録画面と同等の項目構成になっている
- [ ] バリデーション/保存フローが記録画面と一致している
- [ ] 編集完了後、書籍詳細画面の表示が正しく更新される
- [ ] 既存の記録編集（記録画面）は影響を受けない

## 作業内容

### 1) 現行差分の洗い出し

- 記録画面の編集仕様（入力項目/バリデーション/保存処理）を整理
- 書籍詳細画面の編集仕様との差分を特定

### 2) UI/仕様の統一

- 書籍詳細画面の記録編集を、記録画面と同一構成に変更
- 可能であればフォーム/ダイアログの共通化で保守性を上げる

### 3) 影響確認

- 書籍詳細の編集導線（編集 → 保存 → 反映）が崩れていないことを確認

### 4) デザイン依頼（必要な場合）

- 記録画面と同じ UI を書籍詳細画面に適用する際のレイアウト/ボタン配置の最終確認

## 非ゴール

- 記録カードの表示変更
- 記録削除の導線変更
- 書籍詳細画面全体の再設計

## 注意

- 既存の記録編集仕様に合わせることを優先し、独自仕様は追加しない
- 画面間で同じ操作が同じ結果になることを担保する
