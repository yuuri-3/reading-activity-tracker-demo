# TK-029 記録と書籍メモの紐付け（コンポーネントロジック実装）

このチケットは、TK-028 で追加した `bookMemoId` を利用して、記録編集時に関連する書籍メモも取得・更新し、記録削除時には書籍メモも同時削除するか確認する機能を実装する。UI の変更は TK-030 で行う。

## ゴール

- 記録編集時、`bookMemoId` から関連する書籍メモを取得してフォームに表示できる
- 記録編集で書籍メモを変更した場合、書籍メモ側も更新される
- 記録削除時、`bookMemoId` があれば書籍メモも削除するか確認ダイアログを表示
- 既存の動作（書籍メモなしの記録、紐付けのない書籍メモ）に影響を与えない

## 作業内容

### 1) 記録編集時の書籍メモ取得

`src/app/pages/RecordSingleView.tsx` - `handleOpenEditDialog`:

- 記録の `bookMemoId` を確認
- `bookMemoId` があれば、書籍から該当メモを取得してフォームに設定
- なければ従来通り空文字

実装方針:

```typescript
const handleOpenEditDialog = (recordId: string) => {
  const record = records.find((r) => r.id === recordId);
  if (!record) return;

  resetAddForm();
  setEditingRecordId(record.id);
  setSelectedBookId(record.bookId ?? "");
  setMemo(record.memo ?? "");

  // 紐付けられた書籍メモを取得
  if (record.bookMemoId && record.bookId) {
    const book = getBook(record.bookId);
    const linkedMemo = book?.memos?.find((m) => m.id === record.bookMemoId);
    setBookMemo(linkedMemo?.text ?? "");
  } else {
    setBookMemo("");
  }

  setTagIds(record.tagIds ?? []);
  // ... 日時設定
};
```

### 2) 記録編集保存時の書籍メモ更新

`src/app/pages/RecordSingleView.tsx` - `handleConfirmAdd`:

- 編集時（`editingRecordId` あり）の処理を拡張
- 元の記録に `bookMemoId` があり、書籍メモが変更されている場合：
  - 書籍が同じ → 既存の書籍メモを更新
  - 書籍が変更 → 新しい書籍メモを作成し、`bookMemoId` を更新
- 元の記録に `bookMemoId` がなく、書籍メモを新規入力した場合：
  - 新しい書籍メモを作成し、`bookMemoId` を設定

### 3) 記録削除時の確認ダイアログ

`src/app/pages/RecordSingleView.tsx` - `handleDelete`:

- 削除対象の記録に `bookMemoId` があるか確認
- ある場合：
  - 書籍メモの内容を取得（プレビュー用）
  - 確認ダイアログを表示：「この記録と一緒に作成された書籍メモも削除しますか？」
  - 選択肢：「記録のみ削除」「両方削除」「キャンセル」
- ない場合：従来通りトーストで即座に削除（Undo 可能）

実装方針:

```typescript
const handleDelete = async (recordId: string) => {
  const deletedRecord = records.find((r) => r.id === recordId);
  if (!deletedRecord) return;

  // 紐付けられた書籍メモを確認
  if (deletedRecord.bookMemoId && deletedRecord.bookId) {
    const book = getBook(deletedRecord.bookId);
    const linkedMemo = book?.memos?.find(
      (m) => m.id === deletedRecord.bookMemoId,
    );

    if (linkedMemo) {
      // 確認ダイアログを表示（実装は TK-030）
      const shouldDeleteMemo = await showDeleteConfirmDialog(linkedMemo.text);

      if (shouldDeleteMemo) {
        await deleteBookMemo(deletedRecord.bookId, deletedRecord.bookMemoId);
      }
    }
  }

  // 記録を削除
  await deleteRecord(recordId);
  toast.success("記録を削除しました");
};
```

## 注意

- 書籍を変更した場合、元の書籍メモは残す（意図的なデータ保持）
- `bookMemoId` があるのに該当メモが存在しない場合は、空扱いで編集を継続する（警告なし）
- 削除確認はユーザーの選択を尊重（強制削除しない）
- Undo 機能は既存通り維持（ただし書籍メモの復元は同時に行う）
