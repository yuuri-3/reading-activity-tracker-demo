# P0-01 書籍詳細の書籍メモでタグ表示と絞り込み

このチケットは、書籍詳細画面の書籍メモにタグ情報を表示し、タグ単位で絞り込めるようにする。
合わせて、実運用で発生した移行ブロック（TK-011）を、必要な UID のみに限定して解消する。

## ゴール

- 書籍詳細画面の「書籍メモ」カードに、紐づく記録のタグが表示される
- 書籍詳細画面の「書籍メモ」セグメントで、タグ絞り込みができる
- 既存データ（`record.bookMemoId` で紐づくデータ）にも適用される
- `migrationIssues` により停止画面が出る UID を解消する

## 対象

- UI 実装

  - [src/app/components/ListCard.tsx](../../../../src/app/components/ListCard.tsx)
- 運用対応（TK-011 backfill）
  - [functions/src/admin/backfillTk011.ts](../../../../functions/src/admin/backfillTk011.ts)
  - 本番 Firestore `projectId: yomzoy` / `db: (default)`

## 作業内容

### 1) 書籍メモカードにタグ表示を追加

- `ListCard` の `BookNote` バリアントに `tags` / `tagsNode` を追加
- 書籍メモカードの本文下にタグ行を表示できるようにした

### 2) 書籍詳細画面で書籍メモのタグ逆引きと絞り込みを実装

- `BookSingleView` で `records` を走査し、`bookMemoId -> tagIds[]` を構築
- `segment === "book"` 時にタグフィルタ UI（`すべて` + タグチップ）を表示
- 選択タグに一致する書籍メモだけを表示する絞り込みを追加
