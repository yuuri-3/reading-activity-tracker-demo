# UC-003 書籍詳細で書籍メモにタグを表示して絞り込めるようにする

## 概要

書籍詳細画面で表示される「書籍メモ」に、紐づく記録メモのタグを表示し、タグで絞り込めるようにする。
既存データについても、`record.bookMemoId` で紐づいているものは同じ表示/絞り込み対象に含める。

また、今回の作業で検知された `migrationIssues`（TK-011 残件）については、
停止画面を回避するために必要最小限の UID のみバックフィルを実施する。
