# P0-08 OCR 導線の公開（本番フラグ ON 手順含む）

このチケットは、OCR 機能をユーザーが到達できる導線として公開し、本番環境でフラグを ON にして提供開始する最終反映単位です。

## ゴール

- ユーザーが迷わず OCR 新規作成フローを開始できる導線がある
- フラグ OFF では導線が表示されず、既存 UX を壊さない
- 本番でフラグを ON にする手順が明文化されている

## 対象

- 起動導線の設置先（未決: Book 側/Record 側/専用画面）
- [src/app/App.tsx](../../../src/app/App.tsx)
- 関連するページ（導線設置先に応じて）

## 実装状況

Status: ⬜ 未着手

## 受け入れ条件

達成チェック:

- [ ] フラグ ON の環境で、OCR フロー開始ボタンが表示される
- [ ] フラグ OFF の環境では、開始ボタンが表示されない
- [ ] 導線から OCR 編集画面へ到達でき、保存（書籍メモ/記録メモ）まで完了できる
- [ ] 本番環境で `VITE_ENABLE_OCR_HANDWRITTEN_MEMO=true` を設定する手順が記載されている

## 作業内容

### 1) 起動導線の決定と実装

- 01\_要件定義.md の「案 A/案 B」を踏まえ、開始導線を確定する
- UI の詳細（配置/ラベルなど）はデザイン検討待ちでも、最小の導線を実装する

### 2) フラグ ON の運用手順

- 本番環境にフラグを設定 → デプロイ → 確認

## 非ゴール

- カメラ撮影、複数枚、トリミング等の拡張
- OCR 精度改善の追加投資
