# P1-01 カメラ撮影入力の追加

このチケットは、MVP（アルバム選択）に対して、カメラ撮影入力を追加する改善です。Web 環境では権限/挙動差があるため、既存のアルバム選択を必ず代替手段として残します。

## ゴール

- カメラ撮影で画像を用意できる
- 権限拒否/非対応環境ではアルバム選択へフォールバックできる

## 対象

- OCR フローの画像入力 UI（P0-05）

## 実装状況

Status: ⬜ 未着手

達成チェック:

- [ ] 対応環境でカメラ撮影ができる
- [ ] 権限拒否/非対応時にアルバム選択が案内される
- [ ] 撮影した画像はアプリ側に永続保存されない

## 作業内容

### 1) カメラ入力の実装

- Web の制約を踏まえた実装（権限/挙動差を吸収）

### 2) フォールバック導線

- 常にアルバム選択を代替として残す
