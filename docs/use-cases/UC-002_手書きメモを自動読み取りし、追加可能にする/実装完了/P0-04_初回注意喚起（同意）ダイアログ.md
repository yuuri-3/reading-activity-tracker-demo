# P0-04 初回注意喚起（同意）ダイアログ

このチケットは「画像を外部サービスに送って解析する」前提の説明責任として、初回のみ短い注意喚起を表示し、同意状態を端末ローカルに保存する単位です。

## ゴール

- OCR 実行前に、初回のみ注意喚起ダイアログを表示できる
- ユーザーが続行を選んだ場合のみ OCR 実行へ進める
- 同意状態は端末ローカルに保存し、2 回目以降は表示しない

## 対象

- Dialog: [src/app/components/Dialog.tsx](../../../src/app/components/Dialog.tsx)
- （追加予定）OCR 導線/画面
- プライバシーポリシー画面: [src/app/pages/PrivacyPolicyPage.tsx](../../../src/app/pages/PrivacyPolicyPage.tsx)
  - ルート: `/sanctum/privacy`
- 同意状態の永続化: [src/app/ocr/ocrHandwrittenMemoLocalState.ts](../../../src/app/ocr/ocrHandwrittenMemoLocalState.ts)
  - `localStorage` キー: `yomzoy:ocrHandwrittenMemoState:v1`
  - フラグ: `consentAccepted`（`true` の場合はダイアログを出さない）

## 動作確認メモ（手順）

### 1) OCR 機能フラグを ON

- `.env.local`（無ければ作成）に `VITE_ENABLE_OCR_HANDWRITTEN_MEMO=true` を追加

### 2) 開発サーバー起動

- `npm run dev`
- 表示された URL（例: `http://localhost:5173`）を開く

### 3) OCR 入口へ移動

- ブラウザで `/ocr` を開く（例: `http://localhost:5173/ocr`）
- `BASE_URL` を使っている環境では、アプリ base 配下で `/ocr`（例: `/myapp/ocr`）

### 4) 初回同意ダイアログの確認（初回のみ）

- 「OCR を開始」を押す
- 次が表示されること
  - 文言: 「画像は外部サービスに送信して文字認識します（画像は保存しません）。個人情報が写り込まないようご注意ください。」
  - ボタン: 「続行」「キャンセル」
  - リンク: 「プライバシーポリシー」

### 5) 動作分岐の確認

- 「キャンセル」: OCR フローに進まない
- 「続行」: 同意が保存され、OCR フローに進む

### 6) 2 回目以降に出ないことの確認

- ページをリロードしてもう一度「OCR を開始」
- ダイアログが出ずに OCR フローへ進むこと

### 7) リセットして「初回」を作り直す（任意）

- DevTools → Application/Storage → Local Storage でキー `yomzoy:ocrHandwrittenMemoState:v1` を削除
- もしくはコンソールで `localStorage.removeItem("yomzoy:ocrHandwrittenMemoState:v1")`
- リロードして再度「OCR を開始」→ 初回ダイアログが出る
