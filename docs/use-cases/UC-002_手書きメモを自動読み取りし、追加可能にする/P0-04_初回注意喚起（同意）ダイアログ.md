# P0-04 初回注意喚起（同意）ダイアログ

このチケットは「画像を外部サービスに送って解析する」前提の説明責任として、初回のみ短い注意喚起を表示し、同意状態を端末ローカルに保存する単位です。

## ゴール

- OCR 実行前に、初回のみ注意喚起ダイアログを表示できる
- ユーザーが続行を選んだ場合のみ OCR 実行へ進める
- 同意状態は端末ローカルに保存し、2 回目以降は表示しない

## 対象

- Dialog: [src/app/components/Dialog.tsx](../../../src/app/components/Dialog.tsx)
- （追加予定）OCR 導線/画面
- （追加予定）ローカルストレージの同意フラグ

## 作業内容

### 1) 注意喚起ダイアログの実装

- 文言案:

  > 画像は外部サービスに送信して文字認識します（画像は保存しません）。個人情報が写り込まないようご注意ください。

- ボタン: 続行 / キャンセル
- リンク: プライバシーポリシー

### 2) 同意状態の保存

- `localStorage` に保存（端末ローカル）
