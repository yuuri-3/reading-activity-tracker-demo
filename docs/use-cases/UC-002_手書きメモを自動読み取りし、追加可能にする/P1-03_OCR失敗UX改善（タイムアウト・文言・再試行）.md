# P1-03 OCR 失敗 UX 改善（タイムアウト・文言・再試行）

このチケットは、OCR の失敗/遅延時の体験を改善し、ユーザーが確実に復帰できるようにする品質向上です。

## ゴール

- OCR の待ち時間が長い場合にタイムアウト扱いにできる
- 失敗理由に応じて分かりやすい文言を出せる
- 再試行（同一画像/画像選び直し）や手入力への切替がスムーズ

## 対象

- OCR API（P0-03）
- OCR 編集画面（P0-05）

- [ ] 再試行導線が分かりやすい
