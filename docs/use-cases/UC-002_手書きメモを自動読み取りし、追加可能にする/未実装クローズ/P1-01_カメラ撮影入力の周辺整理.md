# P1-01 カメラ撮影入力の周辺整理

このチケットは、既に利用可能なカメラ撮影入力について、Web 環境の権限/挙動差を踏まえた周辺整理を行うものです。

現状のプレビューでは「画像を選択」から OS 標準 UI で「カメラ/アルバム選択」が表示され、撮影→OCR 完了まで実行できることを確認できたため、本チケットは保険的整備として優先度を下げ、未実装クローズ（保留）とします。

## ゴール

- 権限拒否/非対応時にのみ、アルバム選択へのフォールバックを案内できる
- 端末への保存有無は OS/ブラウザ挙動に委ねる方針が明記されている

## 対象

- OCR フローの画像入力 UI（P0-05）
- 対応環境（保証対象）
  - iOS Safari（最新/1 世代前）
  - Android Chrome（最新/1 世代前）
