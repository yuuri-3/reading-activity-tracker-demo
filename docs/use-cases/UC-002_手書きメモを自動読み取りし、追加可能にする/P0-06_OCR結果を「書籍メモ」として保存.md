# P0-06 OCR 結果を「書籍メモ」として保存

このチケットは、OCR で編集したテキストを「書籍メモ（Book.memos）」として保存できるようにする単位です。フラグ ON の範囲内で実装し、既存の一覧/並び替えに自然に乗せます。

## ゴール

- OCR 編集済みテキストを、指定した書籍のメモとして新規追加できる
- 日付+時間を入力でき、その日時で時系列表示される（過去分の登録を想定）
- 低コスト案として、入力日時を `BookMemo.createdAt` に保存する

## 対象

- （追加予定）OCR フローの保存先選択 UI（書籍メモ側）
- 既存の書籍データ/メモ追加ロジック（AppContext 経由の CRUD）
- [src/app/pages/BookSingleView.tsx](../../../src/app/pages/BookSingleView.tsx)

## 作業内容

### 1) 保存先: 書籍メモ

- 書籍選択: 検索できる単一選択ドロップダウン（候補 50 冊未満想定）
- 日時入力: `datetime-local`（既存の手動追加と同等の見た目/操作感）
- 保存後: 画像と OCR 結果はリセットし、書籍選択は維持する

### 2) データ保存

- `BookMemo.text` に OCR 編集テキスト
- `BookMemo.createdAt` にユーザー入力日時（`toISOString()` の文字列で保存）

## 非ゴール

- 書籍メモの既存メモ編集導線への統合
- 画像の保持/保存
