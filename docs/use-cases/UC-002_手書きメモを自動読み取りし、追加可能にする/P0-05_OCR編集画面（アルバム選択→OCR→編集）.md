# P0-05 OCR 編集画面（アルバム選択 →OCR→ 編集）

このチケットは、OCR の最小フロー（画像選択 →OCR 実行 → テキスト編集）を“機能フラグ配下でのみ”提供する単位です。まだ保存先への保存は行いません（次チケット）。

## ゴール

- フラグ ON のときだけアクセスできる OCR 編集画面を用意できる
- アルバム選択した画像を元に OCR を実行し、結果テキストを編集できる
- 元画像のサムネイルプレビューを表示できる（ズーム不要）
- 再試行（画像選び直し）で結果を置き換えられる（履歴は持たない）

## 受け入れ条件

達成チェック:

- [ ] フラグ OFF では OCR 編集画面への導線/ルートが存在しない（ユーザーから見えない）

## 作業内容

### 1) 画像選択（MVP: アルバム）

- Web の `<input type="file" accept="image/*">` 相当で選択できる

### 2) OCR 実行

- P0-04（同意）→ P0-03（OCR API）→ P0-02（callable）を利用して実行

### 3) 編集 UI

- テキスト入力で編集できる
- サムネイル表示
- 再試行（画像選び直し）ボタン
