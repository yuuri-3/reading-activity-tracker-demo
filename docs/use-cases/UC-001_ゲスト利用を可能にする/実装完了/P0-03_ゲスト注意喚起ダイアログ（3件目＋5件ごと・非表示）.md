# P0-03 ゲスト注意喚起ダイアログ（3 件目＋ 5 件ごと・非表示）

## ゴール

- ゲスト利用（匿名ユーザー）で book/record を作り続けると、一定回数で注意喚起する

## 対象

- UI 配置: [src/app/App.tsx](../../../src/app/App.tsx)
- Dialog: [src/app/components/Dialog.tsx](../../../src/app/components/Dialog.tsx)
- 作成イベント: [src/app/context/AppContext.tsx](../../../src/app/context/AppContext.tsx)
- アカウント削除/ゲスト→Google 連携後の掃除: [src/app/auth/AuthContext.tsx](../../../src/app/auth/AuthContext.tsx)
- カウント保存: localStorage（ユーザー uid でキー分離）

## 実装状況

Status: ✅ 完了（受け入れ条件を満たす）

## 決定事項（このチャットで合意済み）

- Dialog 実装方針: 既存の Dialog コンポーネントを拡張して対応する（差分最小）
- カウント加算タイミング: 「作成イベント発火時」ではなく「保存が成功したタイミング」で加算する（タイマー停止による record 作成も同様）
- localStorage キー設計: プロジェクト既存の命名に合わせ、`yomzoy:` prefix + バージョン + `uid` 分離で実装する（詳細は実装側で最終確定）

## 受け入れ条件

達成チェック:

- [x] ゲスト（匿名）で book/record を合計 3 件作成した瞬間にダイアログが出る
- [x] 以降は 5 件ごとに再表示される（ただし「表示しない」を選んだ場合を除く）
- [x] 非匿名（Google ログイン済み）では表示されない

## 作業内容

### 仕様詳細（実装要件）

- 対象ユーザー: `user?.isAnonymous === true` のときのみ
- 対象イベント:
  - book 作成
  - record 作成（手動追加）
  - record 作成（タイマー停止による作成も含む）
- しきい値:
  - 初回表示: `createdCount == 3`
  - 以降: `createdCount == 3 + 5n`（n は 1 以上）
- 「表示しない」:
  - localStorage にフラグ保存
  - true の場合は以後一切表示しない
- 表示文言に含める要素:
  - 「ゲストのままだと端末変更に弱い」こと
  - 「ログインするとデータが Google アカウントに連携され、別端末でも使えるようになる」こと

## 非ゴール

- 重複排除の高度化、競合解決（updatedAt 上書き）は行わない

## 注意

- localStorage のキーはユーザー uid で分離し、ユーザー切り替えで混ざらないようにする
