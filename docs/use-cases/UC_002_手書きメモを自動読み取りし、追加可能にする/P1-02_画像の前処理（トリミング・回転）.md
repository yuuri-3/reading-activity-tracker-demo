# P1-02 画像の前処理（トリミング・回転）

このチケットは、OCR 精度と体験を上げるために、画像の簡易前処理（トリミング/回転）を追加する改善です。

## ゴール

- OCR 実行前に、ユーザーが必要最小限のトリミング/回転を行える
- 前処理後の画像を OCR へ渡せる

## 対象

- OCR フローの画像入力 UI（P0-05）

## 実装状況

Status: ⬜ 未着手

## 受け入れ条件

達成チェック:

- [ ] トリミング/回転ができる
- [ ] 前処理後の画像で OCR を実行できる
- [ ] 画像はアプリ側に永続保存されない

## 作業内容

### 1) 前処理 UI

- トリミング/回転（どこまでやるかは着手時に確定）

### 2) OCR 入力への反映

- 前処理後の画像データを送信する

## 非ゴール

- 高度な補正（傾き補正/コントラスト自動調整など）
