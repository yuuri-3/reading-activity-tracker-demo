# P0-03 ゲスト注意喚起ダイアログ（3件目＋5件ごと・非表示）

## ゴール

- ゲスト利用（匿名ユーザー）で book/record を作り続けると、一定回数で注意喚起する

## 対象

- UI 配置: [src/app/App.tsx](../../../src/app/App.tsx)
- Dialog: [src/app/components/Dialog/Dialog.tsx](../../../src/app/components/Dialog/Dialog.tsx)
- カウント保存: localStorage（ユーザー uid でキー分離）

## 仕様詳細（実装要件）

- 対象ユーザー: `user?.isAnonymous === true` のときのみ
- 対象イベント:
  - book 作成
  - record 作成（手動追加）
  - record 作成（タイマー停止による作成も含む）
- しきい値:
  - 初回表示: `createdCount == 3`
  - 以降: `createdCount == 3 + 5n`（n は 1 以上）
- 「表示しない」:
  - localStorage にフラグ保存
  - true の場合は以後一切表示しない
- 表示文言に含める要素:
  - 「ゲストのままだと端末変更に弱い」こと
  - 「ログインすると別端末でも使える」こと

## 受け入れ条件

- ゲスト（匿名）で book/record を合計 3 件作成した瞬間にダイアログが出る
- 以降は 5 件ごとに再表示される（ただし非表示を選んだ場合を除く）
- 非匿名（Google ログイン済み）では表示されない

## 非ゴール

- 重複排除の高度化、競合解決（updatedAt 上書き）は行わない
