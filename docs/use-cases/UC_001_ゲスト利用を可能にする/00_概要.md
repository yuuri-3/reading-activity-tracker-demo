# UC_001 ゲスト利用を可能にする（指示概要）

このユースケースは、未ログインでも全機能を使えるようにし、ログイン時にゲストデータを Firestore 上で安全に引き継げるようにするための実装指示です。

## 用語

- 画面: 計測（home/TimerPage）, 本棚（books）, 記録（records/RecordsPage）, 書斎（sanctum）
- データ: books / records / tags
  - Firestore は `users/{uid}/books|records|tags` を使用
- UI 部品:
  - Dialog: [src/app/components/Dialog/Dialog.tsx](../../../src/app/components/Dialog/Dialog.tsx)
  - Toast: sonner（`toast`）

## 決定事項（最終）

- ゲストは匿名認証ユーザー（`user.isAnonymous === true`）として扱う（ユーザーが明示的に選んだ時のみ `signInAnonymously()`）
- books/records/tags は常に Firestore を SSoT にする（LocalBackend は作らない）
- Google ログインは link 優先（基本は `linkWithPopup`）。成功時は uid 不変 → 移行不要
- popup が利用できない場合のみ redirect をフォールバック（P0 の「追加のみ移行」は popup 前提）
- link 失敗時のみ anon→既存 uid へ「追加のみコピー」（上書きしない / anon 側は削除しない）
- 統合先は「この端末でログインするアカウント」。Google ログイン開始前に統合確認ダイアログを出す
- 計測（任意/P1）は「匿名ユーザーの初回 record 作成」1回のみ（Firebase Analytics/GA4）
- Cookie 同意ボタンは作らないが、プライバシーポリシー導線はアプリ内に用意する
- link 失敗（追加コピー）/ 匿名認証失敗などの通知は既存 UI（SignInScreen のエラー表示 / Toast）で行う

## 全体アーキテクチャ方針（最小変更）

- 画面やコンポーネントは既存通り AppContext 経由で CRUD を呼ぶ（差し替えない）
- AuthGate は「ログイン必須」ではなく「未ログイン時に SignInScreen を表示」する
  - SignInScreen の「ログインせず利用する」選択時のみ匿名認証で通す
- AppContext は Firestore 購読/CRUD を継続する
