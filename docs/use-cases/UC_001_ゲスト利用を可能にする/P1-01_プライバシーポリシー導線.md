# P1-01 プライバシーポリシー導線

## ゴール

- 同意ボタンは出さず、ユーザーがいつでもプライバシーポリシーを確認できるようにする
- （P1-03 を行う場合）「匿名で初回記録作成のイベントを送る」ことをプライバシーポリシー本文に明示する

## 対象

- 本文（正）: [docs/privacy-policy.md](../../privacy-policy.md)
- UI 導線:
  - 書斎（sanctum）に「プライバシーポリシー」リンクを追加
  - （任意）ゲスト注意喚起ダイアログ内にも補助リンク（テキストリンクのみ）を追加

## 仕様詳細（実装要件）

- 導線は 1 箇所以上（書斎）に必ず置く
- プライバシーポリシーに最低限含める説明:
  - 収集するデータ（匿名イベントの内容）
  - 目的（利用状況の把握・改善）
  - 送信先（Firebase/Google など）
  - ゲスト（匿名ユーザー）時のデータ保存先（Firestore）と、端末内に保存されうる情報（例: タイマー状態・ゲスト注意喚起の非表示フラグ等）

## 受け入れ条件

- アプリからプライバシーポリシーへ遷移できる
- プライバシーポリシー本文に匿名イベント計測の説明が含まれている（P1-03を実施する場合は必須）
